description Contexte

Le client nous a contactés en urgence un samedi matin suite à une fuite d'eau importante au niveau de son WC suspendu encastré. L'eau s'infiltrait derrière le carrelage, menaçant de causer des dégâts des eaux chez le voisin du dessous. Une intervention rapide était cruciale pour limiter les dommages structurels.

troubleshoot Diagnostic

Après démontage de la plaque de commande et inspection endoscopique du bâti-support, nous avons identifié deux problèmes majeurs :

  • error Joint d'étanchéité de la pipe d'évacuation fissuré par l'usure.
  • error Flotteur du mécanisme de chasse entartré, provoquant un écoulement continu.

build Solution apportée

Nous avons procédé au remplacement complet du mécanisme de chasse par un modèle Geberit double touche (économie d'eau) et changé le joint de la pipe d'évacuation sans casser le carrelage, grâce à notre outillage spécialisé pour espaces réduits.

lightbulb Le Conseil du Pro

  • check
    Anticalcaire : Pour les WC encastrés, versez du vinaigre blanc dans le réservoir une fois par an pour éviter que le flotteur ne se bloque.
  • check
    Surveillance : Un léger filet d'eau dans la cuvette est le signe avant-coureur d'une surconsommation. N'attendez pas la fuite franche.
